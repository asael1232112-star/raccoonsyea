Raccoon Menu (Fabric, Minecraft 26.1+, Java 25)

Build:   ./gradlew build        (jar ends up in build/libs/)
Run:     ./gradlew runClient
Needs the Gradle wrapper: if missing, run `gradle wrapper` once (Gradle 9+),
or generate a fresh project at https://fabricmc.net/develop/template/ and
copy src/ into it.

Right Shift opens the menu (rebindable in Controls). Right Shift or Esc closes it.
